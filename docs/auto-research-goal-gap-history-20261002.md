## 我理解的目标

做一个日常可用、按需自主推进科研的研究 Agent。用户只想聊天、问论文或调研领域时，系统完成这些请求即可；用户希望从目标推进到实现与实验时，才进入 Auto Research。研究区共享资料、Notes 和设置，允许多个独立会话，仅从历史消息显式分支才继承历史。

给定“研究 Agent 方向，以 CVPR 质量为目标”的任务，研究 LLM 应能调研近期论文、报告和技术分析，读原文，理解核心方法、输入输出、数据集、代码和局限；提出有依据的研究缺口与待验证假设，选择较新且可复现的 baseline，设计方法和对比/消融实验。用户要三个创新点时，应形成同一课题中可分别验证的三个贡献，而非三个互不相干的选题。

Codex CLI 是研究 LLM 按需调用的工具。研究 LLM 决定何时准备好实现方案、何时委派、如何解释实际指标、是否补调研/改方案/再实验或结束；宿主负责执行范围、预算、状态和测量收据。最终交付代码、数据/配置版本、方法沿革、实验对比、证据与可复验报告。创新、投稿质量与接近 SOTA 需要实际研究支持，不能由模型自述或任务 completed 状态代替。

项目同时服务于求职：覆盖 Agent 开发/算法岗位的工程能力，简历及时使用已有真实成果，之后以更强证据更新。不必为 Codex 接入强造效果指标，也不能把外部编码模型的能力当作自研贡献。

保留 SQLite、木屋界面、已有检索/记忆/压缩/会话基础、用户数据与 .env；下载放 D:/paper。
