# Harness 策略评测预注册（2026-09-21）

目标：在不改变模型权重、不执行任意代码的前提下，将实际失败转为有版本的检索/阅读策略，并用同条件重放决定启用或回退。默认策略保持原流程。反馈不是正确答案，策略建议不等于已证明提升。

冻结基线：data/backups/harness-strategies-20260921-201118/source。数据库与 .env 哈希另存于同目录；评测只使用公开来源及明确标注的合成控制材料，不传送用户聊天。

预先固定的处理组：原混合检索；只加查询规划；只加覆盖重排；完整候选。查询规划最多两条替代表达，原查询始终保留；重排只改变已授权召回的顺序。独立原文阅读、引用验证、会话可见性和工具预算保持一致。规划失败回退到原查询且记录失败。

检索控制集复用 datasets/retrieval/retrieval_questions_v3.json 的 60 题：20 个 Docling 开发题；40 个历史保留题，其中 30 个可回答、10 个无答案。该数据已在以往开发使用，明确称为历史控制集，不宣称本轮盲测。在开发集完成实现后冻结代码再跑其余题。召回分母按原始文档段落；同时报告完整排名与实际交给模型的片段覆盖率，避免排名改善却没有送达。

真实 Luna 对照：固定公开原文任务、问题、模型、索引、工具/上下文预算，基线和候选交替先后；比较正确且有依据的答案、引用/原文覆盖、任务成功、工具数、模型请求、可报告 token（含规划、核验）、延迟。至少六组配对，包含跨文档、数字、机制和无答案问题。保留每次完整轨迹与失败，不用成功重跑替换首次结果。另用小规模无检索模型对照识别参数记忆贡献，不将其称为公平的等成本 Harness 消融。

若 Luna 的双方成功率均接近满分、没有可观察质量差异，再使用现有 DeepSeek 配置进行同条件对照；记录实际 API 模型名，不把别名推断成未证实的供应商版本。补充控制文档可采用明确标注的合成变体，避免模型只凭背诵论文答案，结果与真实论文分开统计。

启用门槛：同一数据/模型/预算/评分口径，至少六组完整配对；候选正确率不降且引用安全不降，质量提高或同质量下平均延迟至少降低 10%；平均 token 不超过 2 倍、平均延迟不超过 2 倍，缺失 token 时不批准成本门槛。门槛不满足则保留候选、默认基线不变。样本级配对区间和少量样本限制必须报告。观察窗至少五次同模型任务，失败率显著劣于批准基线时回退；人工回退始终可用。

不承诺复现简历中的具体百分数。报告原有指标、新指标、无提升的处理组以及运行范围，科学创新候选的自动执行仍属于未实现的 V4。
