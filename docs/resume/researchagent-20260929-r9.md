# ResearchAgent｜研究工作台与 Agent Harness

**技术栈：** Python、SQLite FTS5/BM25、BGE-M3、Chroma、JavaScript、OpenAI-compatible API、Codex CLI。

独立开发面向论文与技术研究的 Agent 工作台，支持聊天、领域调研、资料问答、创新假设与实验档案；自研检索、记忆、证据核验和可恢复执行机制，并扩展可选 Auto Research。

- **Agent Harness 编排与恢复：**自研显式 Agent Loop，串联意图路由、工具调用、原文阅读、答案核验与局部修复，支持预算、取消、检查点和完整 Trace。在 **3 条真实失败草稿**上，均仅补跑 **1 次核验**恢复，复用已有检索与原稿，无需重新检索或生成整份答案。
- **混合检索与原文重排：**以 FTS5/BM25、BGE-M3 和 RRF 构建生产检索链，支持多查询规划、原文重排和失败回退。在 SciFact **5,183 篇摘要、20 道有证据保留题**上，混合检索相对关键词检索的 **Recall@5 从 75.00% 提升至 87.50%，MRR@5 从 0.604 提升至 0.714**；QASPER **28 道完整证据映射保留题**的 Recall@5 从 **44.46% 提升至 52.32%**。
- **可信证据与成果管理：**建立 Claim–Evidence–Source 关联，记录来源、页码、内容哈希与实际阅读窗口，使用独立模型调用核验事实和引用；以 SQLite 管理报告草稿/审核/发布、实体关系、待验证创新假设与实验版本。历史 Luna 配对面板中，12 道可回答题的目标原文片段阅读覆盖 **91.67%→100%**，引用充分事实项 **19/22→20/22**。
- **Memory 与长任务上下文：**实现会话、研究区、全局三级记忆、来源追溯及上下文压缩，支持共享资料/Notes、多独立会话和历史分支。LongMemEval **25 道保留题**的历史会话 Recall@5 **8.33%→37.47%**；真实模型记忆专测 **20/20 通过**，连续两次压缩后的事实与约束检查 **22/24 通过**。
- **反馈驱动策略管理：**将漏检、漏读与引用不足反馈转为有限策略候选，保存不可变版本，通过配对评测、质量/成本门槛和回退管理启用。历史控制集查询规划候选的 **Recall@5 64.92%→72.14%（+7.22 个百分点）**；计量不完整时保留原策略。
- **Coding Agent 工具化与研究编排：**将 Codex CLI 封装为持久化工具，接入研究控制器的方案版本、异步委派与实测结果回传；为研究 LLM 提供调研、项目准备、编码委派和结果检查工具，由模型选择动作。复用已真实运行的受控执行、预算、取消与收据机制，保留代码差异、指标和失败。**Auto Research 工具链已接通，完整真实课题仍在验收。**
- **评测与工程验证：**组织 **320 条“开源＋项目场景”基准**，覆盖 QASPER、SciFact、HotpotQA、LongMemEval，完成 **592 次生产检索、64 次真实 DeepSeek 问答与 24 项工作流回归**，保留正负结果、来源、轨迹和计量；当前工作区 **409 项后端、32 项前端**回归通过。

指标来源及边界见 [r9 证据说明](researchagent-20260929-r9-evidence.md)。检索指标对应生产检索配置对比；Codex 集成作为工程能力描述，不以其生成代码的排序成绩归因研究 Agent。不同日期、模型与样本的结果分别保存。
