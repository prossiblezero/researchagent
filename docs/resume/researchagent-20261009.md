# ResearchAgent｜科研调研与自动实验工作台

**技术栈：**Python、JavaScript、FastAPI、Agent Harness、Agentic RAG、Multi-Agent、SQLite、ChromaDB、Docker

**项目描述：**独立开发面向论文调研的 Agent 工作台，支持多轮论文检索、跨文档问答和报告生成，并可拆分调研任务、调用编码工具开展对比实验。

**主要工作：**

1. **意图识别与任务执行：** 实现结合会话上下文的七类意图路由，在 **MASSIVE 子集与自建场景的 210 题测试集**上，意图识别准确率达 **93.81%**。构建支持工具校验、超时控制与断点续跑的 Agent 执行框架。在 **自建超长资料问答任务集**中，使用相同模型与单次 **16K 上下文预算**，任务完成率达 **85.7%**，比只用 **API＋Prompt**（**35.7%**）提高 **50 个百分点**。其中，在**SciFact 问答子集（6 题、5,183 篇摘要）** 上，任务完成率为 **100%**，高于同条件 API＋Prompt 的 **33.3%**。

2. **Agentic RAG 与跨文档问答：** 由 Agent 按需选择检索时机、根据中间证据调整查询，交替执行检索与原文分页阅读，支持多跳检索、跨文档归纳及段落级引用核验。在自建的**团队论文多跳检索与关系问答任务集**上，任务完成率为 **80%**。底层结合 **FTS5/BM25 关键词检索与 BGE-M3 向量检索**，通过 RRF 融合排序。在 SciFact 检索子集上，相比 BM25，Recall@5 从 **75.0% 提升至 87.5%**，MRR@5 从 **0.604 提升至 0.714**。

3. **记忆与经验学习：** 设计会话记录、研究区共享记忆与全局偏好管理，结合历史混合检索和上下文压缩保留任务进度，并**受 JitRL 的启发**，从任务成败轨迹提炼过程经验，供后续任务按需检索复用。相比原始关键词记忆方案，在 LongMemEval 的 **25 题子集**上，历史召回 Recall@5 从 **8.3% 提升至 33.5%**；在自建 **20 道后续任务**对照中，任务完成率从 **65% 提升至 75%**。

4. **Auto Research 与多 Agent 协作：** 设计“文献调研→方案生成→编码实验→结果反馈”的自动研究闭环，由主控分解任务、协调研究与编码 Agent，自动运行基线、候选及消融实验。生成的候选方案在 **SciFact 开发集证据分类任务**中将 **macro-F1 从 45.04% 提升至 49.00%（+3.96 个百分点）**；在 **HotpotQA 64 题证据检索子集**中将 **Recall@2 从 59.38% 提升至 65.63%（+6.25 个百分点）**。

5. **四维评测与策略改进：** 建立涵盖 QASPER、SciFact、HotpotQA、LongMemEval 及项目场景的 **320 条基础评测任务**，结合确定性检查、**LLM-as-a-Judge** 与原文复核，从事实正确、内容完整、引用支撑和无据添加四个维度评估回答质量。通过受控样例校准裁判，固定参考证据与判定规则，保留原始评分、失败记录和运行成本，为问题定位与策略迭代提供可追溯依据。
