# ResearchAgent｜科研调研与自动实验工作台

**技术栈：**Python、JavaScript、FastAPI、Agent Harness、Multi-Agent、SQLite、ChromaDB、Docker

**项目描述：**独立开发面向论文调研的 Agent 工作台，支持论文检索、原文问答和报告生成，并可拆分调研任务、调用编码工具开展对比实验。

**主要工作：**

1. **任务执行与恢复：**构建 Agent 执行框架，支持任务路由、工具调用校验、超时控制和断点续跑，记录执行过程并核验、修订答案。在覆盖论文问答、事实核验和跨文档推理的 **24 题端到端评测**中，将任务完成率从 **25% 提升至 75%**。

2. **混合检索与原文引用：**结合 **FTS5/BM25 关键词检索与 BGE-M3 向量检索**，通过 RRF 融合排序；支持分页阅读全文，并将回答中的引用定位到原文段落。在 SciFact 检索子集上，相比 BM25，Recall@5 从 **75.0% 提升至 87.5%**，MRR@5 从 **0.604 提升至 0.714**。

3. **记忆与上下文管理：**分别保存会话记录、研究区共享信息和全局偏好，通过历史检索与上下文压缩保留任务进度、关键事实和对应的原文位置。在 LongMemEval 的 **25 题子集**上，历史召回 Recall@5 从 **8.3% 提升至 37.5%**；24 组连续两次压缩测试中，**22 组能准确找回关键事实**。

4. **多Agent写作与Auto Research：**由主 Agent 拆解研究问题，两个子 Agent 并行查阅资料、撰写报告，再汇总研究结论；接入 Codex CLI 编写实验代码，由系统运行对照实验并回传指标，支持根据结果调整方案。多Agent专项评测中，**32 项事实及引用核对全部通过**；在 SciFact 开发集证据分类实验中，候选方案将 macro-F1 从 **45.04%** 提升为 **49.00%**。

5. **评测与策略改进：**建立包含 QASPER、SciFact、HotpotQA、LongMemEval 及项目场景的 **320 条评测任务**，覆盖检索效果、回答与引用质量、任务完成率和运行成本。根据漏检、漏答等反馈提出策略改进，通过前后对照评测决定是否启用，并支持回退。
