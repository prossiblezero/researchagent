# ResearchAgent｜证据驱动研究 Agent 与按需 Auto Research

**技术栈：** Python、SQLite、FTS5/BM25、BGE-M3、Chroma、JavaScript、OpenAI-compatible API、Codex CLI。

独立开发面向论文与技术研究的 Agent 工作台。普通聊天、资料问答和单次调研保持轻量独立；用户明确进入 Auto Research 后，系统才进入“原文证据→研究假设/方案→工具实现→宿主执行与测量→按结果继续、修订、重跑或结束”的研究循环。研究区共享资料、Notes 与设置，同时支持多个独立会话；只有显式从历史消息分支时才继承聊天历史。

- **按需 Auto Research / Agent-as-Tool：**实现显式研究控制器，由研究 LLM 在受控工具集合内决定何时继续检索、阅读原文、形成假设、选择 baseline、设计实验、调用 Codex CLI、读取宿主 measurement，或根据失败结果继续调研、修改方案、重跑和结束。Codex 只承担编码工具职责，宿主独立执行和测量，因此不把 Codex 的编码能力算作研究 Agent 收益。
- **真实反馈迭代验收：**在受控 SciFact 300 条官方开发集 claim、固定 cited-doc 与单 seed 条件下，完成一次研究决策→Codex 委派→宿主测量→结果回传→第二版方案→重跑的功能路径验收；保存 2 版方案、首轮与修订轮的 baseline/candidate/ablation measurement、比较表、代码版本和失败轨迹。首轮 candidate 的 macro-F1 为 **0.4842**，研究模型根据 CONTRADICT F1 **0.1053** 的弱项提出修订，重跑后 macro-F1 为 **0.4917**、CONTRADICT F1 为 **0.1207**。功能路径和反馈路径通过，但严格新增特征消融尚未完成，`scientific_effect_verified=false`；结果用于证明可追溯的反馈编排，不宣称候选方法已被科学验证或达到 SOTA。
- **宿主管理实验边界：**实验代码通过 JSONL 声明模型请求，宿主在沙箱外按调用次数/时间预算调用指定模型并写回响应；保存输入输出哈希、调用收据、耗时、usage、失败和恢复状态，凭据不进入实验环境。该接口作为 Auto Research 的执行边界，Codex 只负责实现，实验结果由宿主独立测量。
- **Agent Harness 与任务恢复：**实现显式 Agent Loop、多工具响应处理、引用核验、局部修复、检查点和 Trace。固定 SciFact **8 题×2 配置**的真实模型复测中，端到端通过率 **31.25%→75.00%（5/16→12/16）**，多工具协议失败 **9/16→0/16**；另在 **3 条真实失败草稿**上复用检索与正文，仅续跑核验完成恢复。
- **混合检索与原文重排：**构建 FTS5/BM25＋BGE-M3＋RRF 检索链，支持多查询规划、原文重排和失败回退。SciFact **5,183 篇摘要、20 道有标准证据的保留题**上，Recall@5 **75.00%→87.50%**、MRR@5 **0.604→0.714**；QASPER **28 道证据完整映射保留题** Recall@5 **44.46%→52.32%**。
- **Memory 与上下文管理：**实现会话、研究区、全局三级记忆、历史检索与结构化压缩，支持研究区共享资料和 Notes、多独立会话及历史分支。LongMemEval **25 道保留题**的历史会话 Recall@5 **8.33%→37.47%**；真实模型记忆专测 **20/20**，连续两次压缩后的事实与约束检查 **22/24**。
- **证据、报告与实验版本：**建立 Claim–Evidence–Source 关联，记录原文页码/章节/哈希/阅读窗口，支持有界分页读取、压缩后续读、逐段引用核验与局部修订；以 SQLite 管理报告草稿/审核/发布、论文/项目/方法/数据集/指标/结论关系、HYPOTHESIS 创新候选及 baseline/实验版本。历史 Luna 配对评测中，**12 道可回答题**的目标原文片段阅读覆盖 **91.67%→100%**，引用充分事实项 **19/22→20/22**。
- **反馈驱动策略管理：**将漏检、漏读和引用不足反馈用于生成有限策略候选，以不可变版本、配对评测、质量/成本门槛与回退管理启用。历史控制集 **30 道可回答题**上，查询规划候选 Recall@5 **64.92%→72.14%（+7.22 个百分点）**；计量不完整时保留原策略。
- **产品能力评测：**组织 **320 条“开源基准＋项目真实场景”任务**，覆盖 QASPER、SciFact、HotpotQA、LongMemEval；完成 **592 次生产检索、64 次真实模型问答和 24 项工作流回归**，保存数据版本、原文来源、运行轨迹、指标与失败案例。

当前可以证明：普通研究能力、证据 Harness、Codex 工具边界，以及一次真实结果驱动的方案修订路径已经实现。距离“给出复杂研究目标后稳定地跨数据集、多 seed 自主调研、实现、实验，并可靠判断继续或收工”仍缺多案例复验、严格消融/统计比较、更稳的长文核验和继续/停止判定。
