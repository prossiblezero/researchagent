## 项目定位

ResearchAgent 是一个按需进入 Auto Research 的证据驱动研究 Agent。普通聊天、论文调研和资料问答保持轻量；用户明确给出复杂研究目标后，研究模型才进入：

```text
目标拆解 → 原文检索/阅读 → Claim–Evidence–Source
→ 待验证假设与 baseline → Codex 实现 → 宿主执行/测量
→ 结果决策 → 继续调研、修订、重跑或结束 → 可追溯报告
```

研究区共享资料、Notes 和设置，允许多个独立会话；只有显式从历史消息分支才继承历史。Codex 是研究模型可调用的编码工具，宿主独立执行和测量，项目收益来自证据约束、状态编排、实验比较、反馈决策、恢复和可查交付。
