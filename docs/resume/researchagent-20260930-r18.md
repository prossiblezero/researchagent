# ResearchAgent｜证据驱动技术研究 Agent 与 Auto Research

**技术栈：** Python、SQLite FTS5/BM25、BGE-M3、Chroma、JavaScript、OpenAI-compatible API、Codex CLI。

独立开发面向论文与技术研究的 Agent 工作台，提供普通聊天、领域调研、资料问答和按需 Auto Research 两种使用方式。研究区共享资料、Notes 与设置，同时支持多个独立会话；只有显式从历史消息分支时才继承聊天历史。系统围绕证据、研究决策和可恢复执行保存来源、假设、方案版本、实验指标与失败轨迹。

- **Auto Research / Agent-as-Tool：**实现显式研究控制器。用户明确进入 Auto Research 后，研究 LLM 根据目标和原文证据决定继续检索、阅读、形成研究缺口与待验证假设、选择 baseline、设计实验、调用 Codex CLI 实现、检查宿主测量、修订方案、重跑或结束；普通聊天和单次调研不会被强制升级。Codex 只作为可恢复的编码工具，宿主执行器独立测量并把结果回传给研究 LLM，不把 Codex 的编码分数算作本项目收益。在 SciFact **300 条官方开发集 claim**上完成一例真实“反馈→方法修订→重跑”：形成**两版方法方案及六组基线/候选/消融结果**，并将 **3 条有效宿主 measurement** 幂等归档到 V3 `experiment_versions`。该案例证明控制链路可以运行，候选仍低于基线，不能据此声称创新有效、SOTA 或稳定自主科研。
- **Agent Harness 与任务恢复：**实现显式 Agent Loop、多工具响应处理、引用核验、局部修复、检查点和 Trace。固定 SciFact **8 题×2 配置**的真实模型复测中，修复后的端到端通过率由 **31.25% 提升至 75.00%（5/16→12/16）**，多工具协议失败 **9/16→0/16**；另在 **3 条真实失败草稿**上复用检索与正文，仅续跑核验完成恢复。
- **混合检索与原文重排：**构建 FTS5/BM25＋BGE-M3＋RRF 检索链，支持多查询规划、原文重排和失败回退。SciFact **5,183 篇摘要、20 道有标准证据的保留题**上，相对关键词检索，**Recall@5 75.00%→87.50%，MRR@5 0.604→0.714**；QASPER **28 道证据完整映射保留题**的 **Recall@5 44.46%→52.32%**。
- **Memory 与上下文管理：**实现会话、研究区、全局三级记忆、历史检索和结构化压缩，支持研究区共享资料、Notes、多独立会话及历史分支。LongMemEval **25 道保留题**的历史会话 **Recall@5 8.33%→37.47%**；真实模型记忆专测 **20/20 通过**，连续两次压缩后的事实与约束检查 **22/24 通过**。
- **证据、报告与实验版本：**建立 Claim–Evidence–Source 关联，记录原文、页码、哈希和实际阅读窗口，支持有界分页读取、压缩后续读、逐段引用核验与局部修订；用 SQLite 管理报告草稿/审核/发布、论文/项目/方法/数据集/指标/结论关系、待验证假设和 baseline/实验版本。Auto Research 父报告在隔离回放中可查 **2 个方案、3 条宿主测量、24 条比较、2 条原文证据**，并通过木屋界面验收。历史 Luna 配对评测中，**12 道可回答题**的目标原文片段阅读覆盖 **91.67%→100%**，引用充分事实项 **19/22→20/22**。
- **反馈驱动策略管理：**将漏检、漏读和引用不足反馈用于生成有限策略候选，以不可变版本、配对评测、质量/成本门槛与回退管理启用。历史控制集 **30 道可回答题**上，查询规划候选 **Recall@5 64.92%→72.14%（+7.22 个百分点）**；计量不完整时自动保留原策略。
- **产品能力评测：**组织 **320 条“开源基准＋项目真实场景”任务**，覆盖 QASPER、SciFact、HotpotQA、LongMemEval；完成 **592 次生产检索、64 次真实模型问答和 24 项工作流回归**，保存数据版本、原文来源、运行轨迹、指标及失败案例。

[指标证据与面试说明](researchagent-20260930-r18-evidence.md)。当前可以证明的是：普通研究能力和证据 Harness 已有多项实测结果，Auto Research 已跑通一例“研究决策→工具委派→宿主测量→方案修订→V3 归档”的初步闭环；距离复杂课题的稳定、多轮、可泛化自主研究仍有工程和实证缺口。
