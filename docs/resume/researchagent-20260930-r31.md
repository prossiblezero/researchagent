# ResearchAgent｜深度调研与自主研究 Agent

**技术栈：** Python、SQLite、FTS5/BM25、BGE-M3、Chroma、Codex CLI。

独立开发论文研究工作台，支持日常聊天、证据调研及按需启动的 Auto Research。

- **自主研究编排：** 设计显式状态机，将 Codex CLI 工具化接入，串联原文调研、方案生成、代码实现与实验反馈；支持基线/消融比较、方案迭代、预算控制及检查点恢复。
- **混合检索 RAG：** 构建 BM25＋BGE-M3＋RRF 检索链与原文重排；在 SciFact 5,183 篇摘要、20 道保留题上，Recall@5 **75.0%→87.5%**，MRR@5 **0.604→0.714**。
- **长任务记忆：** 实现会话/研究区分层记忆、结构化上下文压缩和历史原文回溯；LongMemEval 25 道保留题的历史会话 Recall@5 **8.33%→37.47%**。
- **证据与可靠性：** 建立结论—证据—来源关联，支持逐段引用核验、局部修复及报告/实验版本管理；固定 SciFact 8 题×2 配置复测，端到端通过率 **31.25%→75.0%**。
