# ResearchAgent｜科研调研与自主研究 Agent

**独立开发｜Python · SQLite · Chroma · BGE-M3 · Codex CLI**

独立开发面向论文与技术研究的 Agent 工作台，支持日常问答、深度调研与按需启动的 Auto Research，串联资料检索、证据核验、方案设计和实验反馈。

- **Auto Research 与工具调度：**设计研究控制器，支持目标拆解、原文调研、待验证假设与实验方案生成；以 Agent-as-Tool 方式接入 Codex CLI，由研究 LLM 按需委派代码实现。宿主独立执行基线、候选与消融实验，将实测指标回传给研究模型，驱动补充调研、方案修订、重跑或结束；通过 SQLite 保存方案、实验与报告版本，支持跨轮比较与结果追溯。
- **混合检索与证据追溯：**针对论文术语精确匹配与语义表达差异，构建 FTS5/BM25＋BGE-M3 双路召回，通过 RRF 融合排序；建立 Claim–Evidence–Source 关联，将研究结论绑定到原文片段、页码及来源，供引用核验与报告回查。在 SciFact 子集（20 道保留题、5,183 篇摘要）上，相比 BM25，Recall@5 **75.0%→87.5%**，MRR@5 **0.604→0.714**。
- **分层记忆与上下文管理：**设计会话、研究区与全局偏好分层记忆，支持研究区资料共享和独立会话隔离；长任务采用结构化压缩，保留用户约束、研究进度与证据指针，并按需回读历史原文。为历史会话检索引入关键词与向量混合召回，在 LongMemEval 子集（25 道保留题）上，相比关键词检索，历史会话 Recall@5 **8.33%→37.47%**。
- **Agent Harness 与运行可靠性：**基于显式 Agent Loop 编排多工具调用，结合执行预算、逐段引用核验与局部修复控制任务推进；将执行状态和已提交工具结果保存为检查点，支持中断续跑及已有成果复用。针对多工具协议解析与最终引用交付故障修复后，在同模型、同预算的 SciFact 固定 8 题×2 配置复测中，端到端任务通过率 **31.25%→75.0%**，多工具协议失败由 **9/16 降至 0/16**。
