# r23 简历证据与面试说明

2026-09-30（北京时间）。r23 是对 r22 的表达修订，重点把项目目标明确为“按需进入 Auto Research 的研究 Agent”，并把 Codex 定位为 Agent 可调用的编码工具。没有新增科学指标，也没有把 R3 的失败或尚未复验的修复写成成功。

## 目标定义

普通聊天、论文调研和资料问答保持轻量；复杂研究目标才进入：

```text
拆解目标 → 检索并阅读原文 → Claim–Evidence–Source
→ 形成 HYPOTHESIS 与研究方案 → 选择 baseline/实验
→ 研究 LLM 按需调用 Codex → 宿主执行和测量
→ 根据真实结果补查、修订、重跑或结束
```

研究区共享资料、Notes 和设置，区内允许多个独立会话；只有从历史消息显式分支才继承历史。Codex 的编码能力属于外部工具能力，项目贡献在于证据约束、研究状态、决策编排、实验条件比较、反馈和恢复。

## 不能写成已完成

- 完全自主科研、稳定达到 SOTA 或跨课题泛化；
- Codex 编码成绩证明研究 Agent 有效；
- 多数据集、多 seed 已证明自动继续/停止决策可靠；
- 候选方法已经得到科学验证。

## 当前剩余工作

1. 用宿主管理模型接口完成至少一例真实模型实验，保存收据、哈希、代码、测量和失败记录。
2. 在第二个任务或数据集上复用同一控制器，验证研究 LLM 会根据真实反馈继续、修订、重跑或停止。
3. 检查跨轮方案、baseline、数据划分、代码版本、指标方向和来源条件；条件不一致时不得宣称改进。
4. 继续强化长文原文阅读、引用核验、上下文压缩和失败恢复。
