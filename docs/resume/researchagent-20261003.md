# ResearchAgent｜科研调研与自主研究 Agent

**独立开发｜Python · SQLite · Chroma · BGE-M3 · Codex CLI**

独立开发面向论文与技术研究的 Agent 工作台，支持日常问答、深度调研与按需启动的 Auto Research，串联资料检索、证据核验、方案设计和实验反馈。

- **Auto Research 与 Multi-Agent 协作：**设计“研究主控—双路研究 Agent—Codex 编码 Agent”分层协作，主控按需拆解任务、归并原文证据，以 Agent-as-Tool 委派实现；由宿主执行基线、候选和消融并回传指标，支持方案修订、预算停止与版本追溯。在 A-MEM/LoCoMo 40 题开发案例中，候选证据 Recall@10 **55.09%→58.50%**。
- **混合检索与证据追溯：**针对论文术语精确匹配与语义表达差异，构建 FTS5/BM25＋BGE-M3 双路召回，通过 RRF 融合排序；建立 Claim–Evidence–Source 关联，将研究结论绑定到原文片段、页码及来源，支持引用核验与报告回查。在 SciFact 子集（20 道保留题、5,183 篇摘要）上，相比 BM25，Recall@5 **75.0%→87.5%**，MRR@5 **0.604→0.714**。
- **分层记忆与上下文管理：**设计会话、研究区与全局偏好分层记忆，支持资料共享和独立会话隔离；长任务采用结构化压缩，保留用户约束、研究进度与证据指针，按需回读历史原文。为历史会话检索引入关键词与向量混合召回，在 LongMemEval 子集（25 道保留题）上，相比关键词检索，历史会话 Recall@5 **8.33%→37.47%**。
- **Agent Harness 与运行可靠性：**基于显式 Agent Loop 编排多工具调用，通过预算控制、逐段引用核验和局部修复推进任务；利用 SQLite 检查点、幂等委派和父子取消，支持中断续跑与成果复用。在同模型、同预算的 SciFact 固定 8 题×2 配置复测中，协议解析与引用交付修复使端到端通过率 **31.25%→75.0%**，多工具协议失败 **9/16→0/16**。
