# ResearchAgent｜面向研究任务的 Agent Harness 与可信 RAG 工作台

**技术栈：** Python、SQLite FTS5/BM25、BGE-M3、Chroma、原生 JavaScript、OpenAI-compatible API、Codex CLI。

独立开发支持论文与技术资料研究的 Agent 工作台，覆盖资料采集、混合检索、跨文档问答、证据核验、研究成果管理及受控代码实验。

- **Agent Harness 编排与恢复：**自研显式 Agent Loop，串联意图路由、工具调用、原文阅读、答案核验和局部修复；实现工具/轮次/上下文预算、重复动作抑制、取消控制、检查点恢复及完整 Trace。三条真实失败检查点各用一次核验恢复，**0次重复检索、0次整答生成，原草稿保留**。
- **混合检索与原文重排：**基于 SQLite FTS5/BM25、BGE-M3 和 RRF 实现混合检索，支持多查询规划、原文证据重排及消融对比。调用生产检索链在 SciFact 公开子集、完整 **5,183 篇摘要**中评测，保留题 **Recall@5 75.00%→87.50%，MRR@5 0.604→0.714**；QASPER 保留题 Recall@5 **44.46%→52.32%**。重排接入真实问答，每任务最多2次额外调用，支持结果复用和失败回退。
- **可信证据链路：**构建 Claim–Evidence–Source 关联，区分检索预览和已读原文，保存来源URL、页码、内容哈希及阅读窗口；通过独立模型调用核验事实、引用与问题覆盖。在2026-09-27历史面板完成两组**32题、64次真实Luna配对运行**；首组16题中，12道可回答题的目标原文片段阅读覆盖 **91.67%→100%**，引用充分事实项 **19/22→20/22**。固定响应回放修复2条正确稿误拒，并拦截1条原先误通过的错引；补齐代码块尾注绑定及相邻反例。
- **Memory 与长任务上下文：**实现会话、研究区、全局三级记忆及来源追溯，支持研究区共享资料/Notes与多个独立会话、历史消息分支继承；结构化压缩保留约束、近期工具调用和证据指针，结合提示缓存计量控制长任务上下文。
- **反馈驱动策略版本：**将漏检、漏读、引用不足反馈转为有限策略候选，保存不可变版本与运行归因；以同条件配对评测、模型限定、质量和成本门槛控制启用，支持自动退化回退与人工回退，保留全部失败及未达标结果。
- **Coding Agent 有限实验迭代：**接入本机Codex CLI，形成“冻结假设与基线→编码→宿主开发集选优→锁定最佳→终验”闭环；支持**最多3轮、累计编码时间/token预算、连续无改善早停、进程树取消和收据恢复**。真实对照在2轮无改善后保留基线；原文排序候选在1轮达到开发目标后停止，9道同源新事实终验 **Recall@5 88.89%→100%**。
- **成果与工程质量：**使用SQLite管理报告草稿/审核/发布版本、论文与方法等实体关系、带证据的创新假设和实验配置/结果比较；保持原木屋界面与既有会话能力；组织 **320条“开源＋项目”基准**，完成 **592次生产检索、64次真实DeepSeek问答、24项实际工作流回归**，保存问题、来源、运行轨迹、评分、用量和首轮失败；最终 **370项后端、31项前端** 回归通过。
