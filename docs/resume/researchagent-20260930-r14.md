# ResearchAgent｜证据驱动研究工作台与 Auto Research

**技术栈：** Python、SQLite FTS5/BM25、BGE-M3、Chroma、JavaScript、OpenAI-compatible API、Codex CLI。

独立开发面向论文与技术研究的 Agent 工作台，支持日常聊天、领域调研、资料问答与按需开启的 Auto Research。围绕研究决策构建 Harness，整合混合检索、记忆、原文核验、方案版本和持久工具执行，由研究 LLM 根据目标、证据与实测反馈选择下一步动作。

- **Auto Research / Agent-as-Tool：**设计由研究 LLM 决策的研究控制器，根据目标、原文和实验反馈选择调研、方案修订、实现委派或结束；将 Codex CLI 封装为异步持久工具，以 SQLite 保存方案版本、执行收据和失败。在 SciFact **300 条开发集 claim**上，形成**两版方法方案及六组基线/候选/消融结果**：研究 LLM 根据弱类别表现，将单阶段分类修订为两阶段分类并重新实验，保存负结果；六组逐样本评分独立复核一致。普通聊天与论文调研可独立完成，Auto Research 按需开启。
- **Agent Harness 与任务恢复：**实现显式 Agent Loop、多工具响应处理、引用核验、局部修复、检查点及 Trace。固定 SciFact **8 题×2 配置**的真实模型复测中，修复后的端到端通过率由 **31.25% 提升至 75.00%（5/16→12/16）**，多工具协议失败 **9/16→0/16**；另在 **3 条真实失败草稿**上复用检索与正文，仅续跑核验完成恢复。
- **混合检索与原文重排：**构建 FTS5/BM25＋BGE-M3＋RRF 检索链，支持多查询规划、原文重排和失败回退。SciFact **5,183 篇摘要、20 道有标准证据的保留题**上，相对关键词检索，**Recall@5 75.00%→87.50%，MRR@5 0.604→0.714**；QASPER **28 道证据完整映射保留题**的 **Recall@5 44.46%→52.32%**。
- **Memory 与上下文管理：**实现会话、研究区、全局三级记忆、历史检索与结构化压缩，支持研究区共享资料和 Notes、多独立会话及历史分支。LongMemEval **25 道保留题**的历史会话 **Recall@5 8.33%→37.47%**；真实模型记忆专测 **20/20 通过**，连续两次压缩后的事实与约束检查 **22/24 通过**。
- **证据核验与研究成果管理：**建立 Claim–Evidence–Source 关联，记录原文、页码、哈希与实际阅读窗口，支持有界分页读取、压缩后续读、逐段引用核验与局部修订；区分原文事实与待验证假设，以 SQLite 管理报告草稿/审核/发布、论文与方法关系及实验版本。历史 Luna 配对评测中，**12 道可回答题**的目标原文片段阅读覆盖 **91.67%→100%**，引用充分事实项 **19/22→20/22**。
- **反馈驱动策略管理：**将漏检、漏读和引用不足反馈用于生成有限策略候选，以不可变版本、配对评测、质量/成本门槛与回退管理启用。历史控制集 **30 道可回答题**上，查询规划候选 **Recall@5 64.92%→72.14%（+7.22 个百分点）**，计量不完整时保留原策略。
- **产品能力评测：**组织 **320 条“开源基准＋项目真实场景”任务**，覆盖 QASPER、SciFact、HotpotQA、LongMemEval；完成 **592 次生产检索、64 次真实模型问答和 24 项工作流回归**，保存数据版本、原文来源、运行轨迹、指标与失败案例。
