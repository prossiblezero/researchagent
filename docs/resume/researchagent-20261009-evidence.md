## 正文采用的同题阶段对照：25.0%→75.0%

在已冻结的24题上重新运行09-29修复前旧版，与已保存的当前版首次结果比较。QASPER、SciFact、HotpotQA和项目资料问答各6题；严格完成要求产品成功交付、答案正确完整、引用充分且无实质性错误添加。

|成功交付，尚未计入答案质量|9/24|21/24|

严格完成提高50.0个百分点，逐题13个改善、1个退化；配对差值95% bootstrap区间为25.0至70.8个百分点。见[同题对照报告](../../research-notes/legacy-24-20261009/report.md)、[逐题指标](../../research-notes/legacy-24-20261009/metrics.json)及[冻结协议](../../research-notes/legacy-24-20261009/protocol.json)。这衡量09-29到当前的整体本地问答链路变化，不是最近一次小迭代单独贡献50个百分点，也不是320条任务的全量成绩。

两版使用同一题目、资料、模型和评分标准，没有累计、单任务或输出token上限。新增24个旧版首次任务，当前版24个首次结果及已有原文复核原样复用；两版在不同时段运行，没有控制服务负载与模型后端漂移。没有重跑取最好成绩，也没有改旧版源码来通过题目。

旧版原始自动评分为7/24，实施代理复核9份交付答案及原文后纠正1处：dist_based答案虽正确给出mean±3σ，却额外宣称归一化结果为0–1；代码未做截断，10个0和1个1可得1.0270462767。按冻结的“无实质性错误添加”标准降为失败，复核后为6/24；原始评分和数值反例见[复核记录](../../research-notes/legacy-24-20261009/adjudications.json)。24次外部评分中23次有效，另一次字段错误对应的任务本身已执行失败，不改变最终结论。复核者是实施代理，不是独立人工盲评。即使用原始评分，旧版也为29.2%，与当前75.0%的差值为45.8个百分点。

旧版平均59.89秒，当前151.61秒；旧版大量提前失败使均值更短，不能据此声称当前更快。旧版任务请求135次、已知729,566 token（4次未知），当前238次、已知1,828,540 token（3次未知）；这组结果体现交付质量改善，不作为节省token的成绩。

这是项目既有评测池中预先冻结的子集：QASPER、SciFact、HotpotQA、项目问答各6题。公开题来自已有 held_out 池，排除上轮诊断的四篇论文；项目题是历史场景。按题型配额和固定哈希选择，未按答题成绩筛选。两版共48次真实任务，不将旧四题合并进来，也不把24题成绩写成320条任务全部通过。

使用相同模型 `api.sudocode.chat / deepseek-v4-1-flash`、temperature=0、相同资料和策略。两版均未设置累计、单任务或输出token上限；同为8次工具尝试、12轮、16,384上下文和600秒核心循环期限。运行完整本地问答与报告保存，路由显式指定；每次任务有隔离的数据状态。

初始评分使用同模型的独立请求，隐藏版本身份，检查参考答案和实际引用证据。随后实施者复核全部失败及配对版本、每类按固定哈希抽取的一道双通过题和一项预览引用问题，共14对、28份答案。[复核记录](../../research-notes/subset-e2e-20261009/adjudications.json)修正两处相反方向的评分错误：MCScript分页元数据说明有真实工具依据，after由失败改为通过；词嵌入题的范围限定不满足冻结的无答案拒答要求，after由通过改为失败。原始和复核总分均为17/24→18/24，原始答案及评分未覆盖。复核者是实施代理，不是独立人工盲评。

这次净增1题，属于小幅观察改善：3题改善、2题退化；20道可回答题均完成15道，无答案/NEI题从2/4到3/4。配对差值95% bootstrap区间为-12.5至20.8个百分点，包含零。这些增量结果用于记录本次迭代的效果，不替换正文的项目基准，也不据此声称稳定提升全部研究任务能力。

两道退化题的草稿内容正确，但内部核验服务/响应结构导致产品交付失败，仍计入失败。程序返回成功是20/24→21/24，不能替代严格完成率。模型请求258→238；已知token为1,787,515→1,828,540，分别另有4次、3次未知用量，不作为省token成绩。外部评分另有48次请求、254,070 token。

## 第4条的评测范围

正文“多Agent写作与Auto Research”的两项结果来自不同验收：32项事实及引用核对来自多Agent专项评测；macro-F1来自SciFact R4方法实验。

多Agent指标衡量所答事实是否正确、是否有原文支持及引用是否充分。逐项复核文件中14份与任务要求匹配的回答共32项检查，三个字段全部为true。它们来自4道场景题的重复运行，对应9种不同的题目—事实组合，不是32个独立事实问题。另两份任务转交失配回答的4项事实只作补充观察，不纳入这32项；严格任务合同仍为6/8。两份ReAct lookup表述略含糊，按原复核中一致的Ctrl+F语境标准接受，备注保留。原文复核由实施代理完成，不是独立人工盲评；不据此声称通用准确率100%或整体并行提速。

SciFact案例以词/字符TF-IDF及线性分类器为基线，候选加入重叠、长度和否定交互特征，另运行去除否定交互的消融。使用官方train训练、dev评估；dev的300条claim展开340条候选文档记录，包含339个唯一claim/doc对。正文明确标注开发集与证据分类，未将其写成完整检索问答任务或未见测试集成绩。该结果是单seed案例方案的表现，不把外部Codex编码与候选方法的全部收益归因于Agent执行框架。原始子调研未全部通过核验，后续有实施代理补做的原文与代码审阅，详细记录保留在案例报告中。

## 面试表述

“我做了一个面向论文调研的 Agent 工作台，可以检索论文、结合原文回答问题并生成报告。复杂任务会拆给多个 Agent 并行处理，需要验证方案时，可以调用编码工具，再执行对比实验。主要改进是让任务能顺利执行，并在交付前核对答案和引用。在24题端到端评测中，任务完成率从25%提升到了75%。检索和记忆也有各自的专项评测，详细记录保存在项目里。”

这次修改属于原文问答、上下文和Harness可靠性工程；没有测出新的长期记忆、自动skills沉淀或自进化收益。不同条目的历史检索指标与当前端到端指标各自保留模型、数据和比较条件。
