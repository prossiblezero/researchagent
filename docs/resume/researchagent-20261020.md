# ResearchAgent｜科研调研与自动实验工作台

**技术栈：** Python、FastAPI、PyTorch/PEFT、SQLite、ChromaDB

**项目简介：** 面向论文调研与实验验证的自动化需求，针对**资料分散、上下文受限及实验迭代依赖人工**的问题，独立设计并开发支持跨文档问答、经验复用与自动实验的科研 Agent 工作台。

- **意图路由：** 参考 Jev 决策模型的思路，将 Qwen3-0.6B 经 LoRA 训练为意图决策模型，对候选意图做 log-prob 打分并输出校准概率，低置信与自动研究请求回退 LLM；160 题保留集准确率 **98.75%**，p50 时延 **6.4s→4.0s**，远程请求减少 **42%**。
- **Agentic RAG：** 融合 BM25＋BGE-M3，由 Agent 按需交替检索、原文阅读与引用核验，构建 **LLM-as-a-Judge** 四维离线评测与裁判校准；14 题超长资料问答完成率 **85.7%**，单次 API＋Prompt 基线为 **35.7%**。
- **记忆与经验复用：** 设计分层记忆与上下文压缩，受 JitRL 启发从任务成败轨迹提炼经验供后续检索复用；20 道后续任务中，相比关键词记忆，完成率 **65%→75%**。
- **Multi-Agent 自动研究：** 设计主控—Worker 分层编排，构建“调研→方案→实验→反馈”闭环，由宿主执行实验并评分；生成候选在 SciFact 证据分类开发集上 macro-F1 **45.04%→49.00%**。
