# ResearchAgent｜科研调研与自动实验工作台

**技术栈：** Python、FastAPI、PyTorch/PEFT、SQLite、ChromaDB

**项目描述：** 面向论文调研与实验验证的自动化需求，针对资料分散、上下文受限及实验迭代依赖人工的问题，独立设计并开发支持跨文档问答、经验复用与自动实验的科研 Agent 工作台。

**主要工作：**

1. **意图路由：** 基于 Qwen3-0.6B＋LoRA 构建候选打分、置信度校准与 LLM 回退级联；160 题保留集准确率 **98.75%**，相比原 LLM 路由，p50 时延 **6.4s→4.0s**，远程请求减少 **42%**。
2. **Agentic RAG 与评测：** 融合 BM25＋BGE-M3，串联多轮检索、原文阅读与引用核验，构建 **LLM-as-a-Judge** 四维离线评测与裁判校准；14 题超长资料问答完成率 **85.7%**，固定原文前缀的单次 API 基线为 **35.7%**。
3. **记忆与经验复用：** 设计分层记忆与上下文压缩，从任务轨迹提炼经验供后续检索复用；20 道后续任务中，相比关键词记忆配置，完成率 **65%→75%**。
4. **Multi-Agent 自动研究：** 设计主控—Worker 分层编排，支持并行调研与编码委派，由宿主执行实验并反馈迭代；生成候选在 SciFact 开发集的 macro-F1 **45.04%→49.00%**。
