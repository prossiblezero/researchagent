# ResearchAgent｜基于 Agent Harness 的可信 RAG 与反馈驱动研究助手

**项目背景：**面向论文与技术资料研究，独立设计并实现支持资料收集、跨文档问答、证据核验和研究成果管理的 Agent 工作台，针对检索遗漏、引用失配、长会话上下文膨胀及任务中断等问题，构建可追溯、可恢复、可评测的研究流程。

**解决方案：**

- **Agent Harness 编排与治理：**自建显式 Agent Loop，整合意图路由、工具调用、原文阅读、答案核验与失败修复；通过工具/轮次/上下文预算、重复动作抑制、取消控制及检查点恢复约束执行，保存完整 Trace 和请求级 token、延迟记录。
- **混合检索与查询规划：**基于 SQLite FTS5/BM25、BGE-M3 与 Chroma 构建混合检索，结合 RRF 融合及 LLM 多查询规划，兼顾精确术语与语义召回；新增基于候选原文的证据重排，验证来源片段并记录调用成本，支持检索消融和逐题回放。
- **可信证据与引用链路：**区分搜索预览和已读原文，建立 Claim–Evidence–Source 关联，保留页码、来源 URL、内容哈希和读取范围；通过独立模型调用核验事实与引用，将证据不足、核验失败和待核验草稿显式呈现。
- **分层 Memory 与上下文管理：**实现会话、研究区和全局三级记忆及来源追溯，支持独立会话与历史分支；通过结构化压缩保留约束、近期工具调用和证据指针，结合稳定提示前缀与缓存计量管理长任务上下文。
- **反馈驱动策略优化：**将漏检、漏读和无依据结论反馈转为有限检索/阅读策略候选，建立不可变版本、同条件配对评测、模型限定启用和任务归因；设置质量、引用与成本门槛，支持运行退化自动回退及手动回退。
- **Coding Agent 实验闭环：**接入本机 Codex CLI，将研究假设转为冻结实验合同，在独立目录实现候选代码，由固定评测器计算指标并与锁定基线比较；实现超时/取消进程树清理、预算门禁、不可变结果版本和检查点恢复。新增开发反馈链：编码阶段只暴露开发题、开发标签、失败原文和语义排名诊断，测试标签留在宿主，候选由宿主独立计分；保留首候选与修订快照，以开发集选优、质量非下降和退步回退控制候选，再对锁定代码终验。
- **研究成果管理：**基于 SQLite 实现报告版本及草稿/审核/发布流程、论文与方法等实体关系、带原文依据的创新假设，以及基线、实验配置和外部结果的版本比较，支持从研究过程追溯到结论依据。

**项目成果：**

- 构建 **60 题检索评测集与四组消融实验**；在历史控制集的 30 道可回答问题上，查询规划使 **Recall@5 从 64.92% 提升至 72.14%，Recall@10 从 75.87% 提升至 89.76%，MRR 从 0.570 提升至 0.625**，实际证据片段送达率提升 **13.33 个百分点**。
- 完成最终版本 **8 题、16 次真实 Luna 配对运行**，完整任务通过率 **62.5%→75.0%**，平均耗时 **152.9→131.4 秒**；保存全部答案、来源、调用轨迹及失败案例，完成 **78/78 原文快照一致性检查**。
- 修复列表证据绑定与核验恢复：在 **3 条历史引用失配案例**的真实模型回放中，通过数 **0/3→3/3**，错误事实、错引来源和仅摘要引用 **3/3 拦截**；验证中断后复用已通过段落，完成局部修订，无重复检索及整答生成。
- 在 **6份公开资料、151段原文、60道历史问题**上完成 **2条真实编码实验闭环、4次基线/候选测量**；正确保留未达标结果及超时/超预算失败，验证恢复时 **0次新增编码调用**，并通过真实进程超时与取消清理检查。
- 针对生成策略导致的排序退化，完成**诊断→原文证据重排→开发选优→锁定后终验**：在同语料的30道历史可回答题上，**Recall@5 64.92%→94.84%，MRR 0.560→0.950**；其中10道跨文档题 **Recall@5 36.43%→92.86%**，零召回题 **6→0**。
- 增加24道开发题和12道新事实终验题，Luna编码 **93.7秒**交付候选；9道可回答新终验 **Recall@5 88.89%→100%**。对固定的24份模型输出回放，修复合法重复引用解析使异常回退 **9/24→0/24**；最终信号 **191/191条原文引用逐字匹配**。
