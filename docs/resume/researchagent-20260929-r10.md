# ResearchAgent｜证据驱动研究工作台与 Agent Harness

**技术栈：** Python、SQLite FTS5/BM25、BGE-M3、Chroma、JavaScript、OpenAI-compatible API、Codex CLI。

独立开发面向论文与技术研究的 Agent 工作台，支持日常聊天、领域调研、资料问答与研究成果管理；自研检索、记忆、证据核验和可恢复执行机制，扩展由研究 LLM 自主选择工具的可选 Auto Research。

- **Agent Harness 与任务恢复：**实现显式 Agent Loop，串联意图路由、检索阅读、工具调用、引用核验与局部修复，支持预算控制、取消、检查点和 Trace。对 **3 条真实失败草稿**，均仅补跑 **1 次核验**完成恢复，复用既有检索与原稿，避免重跑整条问答链。
- **混合检索与原文重排：**构建 FTS5/BM25＋BGE-M3＋RRF 生产检索链，支持多查询规划、原文重排及失败回退。在 SciFact **5,183 篇摘要、20 道有标准证据的保留题**上，相对关键词检索，**Recall@5 75.00%→87.50%，MRR@5 0.604→0.714**；QASPER **28 道证据完整映射保留题**的 **Recall@5 44.46%→52.32%**。
- **证据核验与研究档案：**建立 Claim–Evidence–Source 关联，追溯原文、页码、内容哈希和阅读窗口，独立调用模型核验事实与引用；使用 SQLite 管理报告草稿/审核/发布、论文与方法关系、待验证创新假设及实验版本。历史 Luna 配对评测中，12 道可回答题的目标原文片段阅读覆盖 **91.67%→100%**，引用充分事实项 **19/22→20/22**。
- **Memory 与长任务上下文：**实现会话、研究区、全局三级记忆、历史检索和上下文压缩，支持研究区共享资料与 Notes、多独立会话及按历史分支。LongMemEval **25 道保留题**的历史会话 **Recall@5 8.33%→37.47%**；真实模型记忆专测 **20/20 通过**，连续两次压缩后的事实与约束检查 **22/24 通过**。
- **反馈驱动策略版本：**将漏检、漏读、引用不足反馈用于有限策略候选，保存不可变版本，通过配对评测、质量/成本门槛和回退管理启用。历史控制集 **30 道可回答题**上，查询规划候选 **Recall@5 64.92%→72.14%（+7.22 个百分点）**；计量不完整时保留原策略。
- **Coding Agent 工具化：**将 Codex CLI 封装为研究 LLM 可调用的持久工具，接通方案版本交接、项目环境准备、异步编码委派与执行结果回传；研究控制器选择调研、检查、委派或结束，宿主管理预算、执行收据与产物。普通聊天和单次调研保持独立路径。**Auto Research 工具编排已实现，完整真实课题仍在联调验收。**
- **评测体系：**组织 **320 条“开源基准＋项目真实场景”任务**，覆盖 QASPER、SciFact、HotpotQA、LongMemEval；执行 **592 次生产检索、64 次真实模型问答和 24 项工作流回归**，关联保存数据版本、原文来源、运行轨迹、指标及失败案例。

配套：[指标证据与面试说明](researchagent-20260929-r10-evidence.md)。以上指标分别对应检索、阅读引用、记忆、恢复和策略配置；Codex 接入描述工程能力，Auto Research 完整科研闭环不提前写为已验收成果。
