# ResearchAgent｜证据驱动技术研究 Agent 与按需 Auto Research

**技术栈：** Python、SQLite、FTS5/BM25、BGE-M3、Chroma、JavaScript、OpenAI-compatible API、Codex CLI。

独立开发面向论文与技术研究的 Agent 工作台。普通聊天、资料问答和单次调研保持轻量独立；用户明确进入 Auto Research 后，系统才进入“读原文→建立证据→形成研究缺口与待验证假设→选择 baseline→设计实验→按需调用编码工具→宿主执行与测量→根据结果继续、修订、重跑或结束”的研究循环。研究区共享资料、Notes 与设置，同时支持多个独立会话；只有显式从历史消息分支时才继承聊天历史。

- **按需 Auto Research / Agent-as-Tool：**实现显式研究控制器，由研究 LLM 决定何时继续检索、阅读原文、形成假设、选择 baseline、设计实验、调用 Codex CLI、读取宿主 measurement，或根据失败结果继续调研、修改方案、重跑和结束。Codex 只承担编码工具职责，宿主独立执行和测量，不把 Codex 的编码分数算作研究 Agent 收益。在 SciFact **300 条官方开发集 claim**的固定 cited-doc 子任务上完成一次真实“研究决策→Codex 委派→宿主测量→结果回传→第二版方案→重跑”：保存**两版方案、8 组有效宿主 measurement 和 24 条比较记录**。第二版把 accuracy 从 **0.5235 提到 0.5353**，但 macro-F1 从 **0.4848 降到 0.4669**、CONTRADICT F1 从 **0.2545 降到 0.1314**，预算耗尽且整体门槛 `passed=false`；该结果证明了反馈、修订和失败保留链路，不声称创新有效或达到 SOTA。
- **宿主管理实验模型接口：**实验代码通过 JSONL 声明模型请求，宿主在沙箱外按调用次数/时间预算调用指定模型并写回响应；保存输入输出哈希、调用收据、耗时、usage、失败和恢复状态，凭据不进入实验环境。接口回归 **49/49** 通过，本轮尚未将接口测试写成新的科学结果。
- **Agent Harness 与任务恢复：**实现显式 Agent Loop、多工具响应处理、引用核验、局部修复、检查点和 Trace。固定 SciFact **8 题×2 配置**的真实模型复测中，端到端通过率 **31.25%→75.00%（5/16→12/16）**，多工具协议失败 **9/16→0/16**；另在 **3 条真实失败草稿**上复用检索与正文，仅续跑核验完成恢复。
- **混合检索与原文重排：**构建 FTS5/BM25＋BGE-M3＋RRF 检索链，支持多查询规划、原文重排和失败回退。SciFact **5,183 篇摘要、20 道保留题**上 Recall@5 **75.00%→87.50%**、MRR@5 **0.604→0.714**；QASPER **28 道证据完整映射保留题** Recall@5 **44.46%→52.32%**。
- **Memory 与上下文管理：**实现会话、研究区、全局三级记忆，历史检索、结构化压缩、检查点和恢复。LongMemEval **25 道保留题**的历史会话 Recall@5 **8.33%→37.47%**；真实模型记忆专测 **20/20**，连续两次压缩后的事实与约束检查 **22/24**。
- **证据、报告与实验版本：**以 SQLite 管理 Claim–Evidence–Source 绑定、原文页码/章节/哈希/阅读窗口、报告草稿/审核/发布、论文/项目/方法/数据集/指标/结论关系、HYPOTHESIS 创新候选及 baseline/实验版本。隔离 Auto Research 父报告可查 **2 个方案、8 组宿主测量、24 条比较、2 条原文证据**；历史 Luna 配对评测中，**12 道可回答题**的目标原文片段阅读覆盖 **91.67%→100%**，引用充分事实项 **19/22→20/22**。
- **反馈驱动策略管理：**将漏检、漏读和引用不足反馈生成有限策略候选，以不可变版本、配对评测、质量/成本门槛和回退管理启用。历史控制集 **30 道可回答题**上查询规划候选 Recall@5 **64.92%→72.14%（+7.22 个百分点）**；计量不完整时自动保留原策略。
- **产品能力评测与可追溯性：**组织 **320 条“开源基准＋项目真实场景”任务**，覆盖 QASPER、SciFact、HotpotQA、LongMemEval；完成 **592 次生产检索、64 次真实模型问答和 24 项工作流回归**，保存数据版本、原文来源、运行轨迹、指标、失败与恢复记录。最新工程回归 **444/444 后端、33/33 前端**。

当前可证明的是：普通研究能力、证据 Harness，以及一次真实的“结果回传→方案修订→重跑”Auto Research 结构路径已经实现；距离“给出复杂研究目标后稳定、多轮、跨数据集自主完成并可靠判断收工”仍缺多案例、多 seed、稳定的科学改进和更强的继续/停止判定证据。
