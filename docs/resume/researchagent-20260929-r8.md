# ResearchAgent｜研究工作台与 Agent Harness

**技术栈：** Python、SQLite FTS5/BM25、BGE-M3、Chroma、原生 JavaScript、OpenAI-compatible API、Codex CLI。

独立开发面向论文与技术研究的 Agent 工作台，支持日常聊天、领域调研、资料问答、证据驱动的创新假设与实验管理，集成检索、记忆、证据核验及注册实验的受控代码执行。

- **Agent Harness 编排与恢复：**自研显式 Agent Loop，串联意图路由、工具调用、原文阅读、答案核验与局部修复；实现执行预算、重复动作抑制、取消、检查点和完整 Trace。在 **3 条真实失败草稿**上均仅补跑 **1 次核验**完成恢复，复用已有检索结果与原稿，无需重复检索或重新生成整份答案。
- **混合检索与原文重排：**基于 SQLite FTS5/BM25、BGE-M3 和 RRF 构建混合检索，支持多查询规划、原文重排及失败回退。使用生产检索链在 SciFact 公开子集、完整 **5,183 篇摘要**中评测，有证据保留题 **Recall@5 75.00%→87.50%，MRR@5 0.604→0.714**；QASPER 完整证据映射保留题 Recall@5 **44.46%→52.32%**。
- **可信证据与研究成果：**构建 Claim–Evidence–Source 关联，保存来源、页码、内容哈希和实际阅读窗口，通过独立模型调用核验事实与引用；SQLite 管理报告草稿/审核/发布版本、实体关系、带证据的创新假设及实验比较。在历史 Luna 配对面板中，12 道可回答题的目标原文片段阅读覆盖 **91.67%→100%**，引用充分事实项 **19/22→20/22**。
- **Memory 与长任务上下文：**实现会话、研究区、全局三级记忆及来源追溯，支持共享资料/Notes、多独立会话与按历史位置分支；在 LongMemEval **25 道保留题**上，混合检索的历史会话 **Recall@5 8.33%→37.47%**。真实模型历史专测中，召回/更新/过期/遗忘等记忆场景 **20/20 通过**；连续两次压缩后的事实与约束检查 **22/24 通过**。
- **反馈驱动策略管理：**将漏检、漏读和引用不足反馈转为有限策略候选，保存不可变版本及运行归因；通过同模型配对评测、质量/成本门槛及回退机制管理启用。历史控制集查询规划候选 **Recall@5 64.92%→72.14%（+7.22 个百分点）**；计量不完整时保留基线，避免未充分验证的候选直接生效。
- **Coding Agent 接入与实验执行：**封装本机 Codex CLI 执行适配器，在注册检索实验中接通方案与基线锁定、编码、实际评测、开发集选优和独立终验，支持最多 **3 轮**有限迭代；实现累计时间/token 预算、无改善早停、进程树取消、执行收据及中断恢复，保留代码差异、原始指标与失败记录。
- **评测与工程验证：**组织 **320 条“开源＋真实项目”基准**，覆盖 QASPER、SciFact、HotpotQA、LongMemEval 及项目场景，完成 **592 次生产检索、64 次真实 DeepSeek 问答及 24 项实际工作流回归**；留存来源、回答、运行轨迹、评分、用量与失败。该基准版本 **370 项后端、31 项前端**回归通过。

指标范围、原始报告及当前实现边界见 [r8 证据说明](researchagent-20260929-r8-evidence.md)。以上描述已实现并有既有验收依据的能力；Auto Research 控制器已接入工作台，正在进行完整真实课题验收，暂未列为已完成成果。
