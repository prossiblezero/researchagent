## 复现真实任务

在实际项目目录使用已配置的环境运行：

```powershell
conda activate evidence-agent
python -B evals/run_v2_benchmark.py --download-root D:\paper
```

## 更新与回退

`deploy-v2.ps1`（隔离实现目录）包含固定文件清单与源文件哈希检查，升级前检查研究任务均处于终态、最近消息已回复，并核实监听进程的 PID、解释器及启动参数。先备份变更前源码和一致性 SQLite 快照，再复制代码并用原 `.env` 启动。`.env`、原始报告、下载文件和用户会话不会被测试数据替换。

回退必须使用升级前的源码与数据库备份配对进行；V1 的旧 SQL 插入语句与新增列并不完全兼容，不能仅恢复 V1 源码后继续写 V2 数据库。若用户已经产生新的 V2 记录，先另存当前数据库再决定迁移或回退，不能直接覆盖新记录。

## 真实能力边界

没有 OCR、公式和复杂表格的视觉理解；只读 GitHub 最多十个关键文件，不是整个仓库运行验收；全文索引与单次模型使用的摘录数量分开展示。引用校验确认位置和摘录存在，尚未建立语义支持率或答案正确率的人工评测。V3/V4 未在本阶段实现。
