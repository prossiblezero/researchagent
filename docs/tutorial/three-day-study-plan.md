## 第一天：建立一条完整故事（6 小时）

1. **1 小时：读故事章第一至五节、第七节。** 理解用户为什么需要工作台，从“材料没找齐、上下文装不下、回答漏证据”进入设计。先画五个框：用户 → Workbench → ResearchAgent → 工具与证据 → 持久化。
2. **2 小时：读 01、03–08。** 每题先读“答”，不理解的地方再读“解析”；把入口、工具循环、原文证据和核验连起来。后台请求可以先入队 pending_route，再由 worker 路由；不要把所有路径都画成先分类再入队。
3. **1 小时：读 11、12、61。** 分清 BM25、BGE-M3、RRF、chunk、阅读窗口，以及普通 RAG 与按观察继续检索的区别。
4. **1 小时：口述两遍。** 第一遍 90 秒项目介绍，第二遍 5 分钟解释一次资料问答。只看关键词，不读全文。
5. **1 小时：自问并补缺。** 为什么不用一次 API？为什么不用 LangGraph？为什么检索完还要读原文？核验发现漏项后发生什么？

完成标准：能把流程讲顺，并用“MemorySaver 重启持久化＋LlamaIndex 查询数量”案例解释为什么需要跨文档补证据。读已有案例即可。

## 第二天：练出可连续展开的技术深点（6 小时）

1. **2.5 小时：65、68–70，配合故事章第十二节。** 理解分类与生成拆分、候选序列 log-prob、每种顺序内的 KV Cache 共享、正逆序平均、LoRA、交叉熵、KL、温度缩放与回退。
2. **1 小时：57、58、66，配合故事章第八节。** 分清历史、事实记忆、过程经验和当前输入；解释上下文压缩保护工具调用对与证据指针。讲清记忆写入、检索、选择、实际使用各是不同环节。
3. **1 小时：41–43、46–47，配合故事章第十节。** 解释主控决定下一步、研究子任务独立工作、编码工具生成代码、宿主执行与评分。记住双路并行在已有对照中并未整体提速。
4. **1.5 小时：连续追问。** 先把路由讲 5 分钟，再让追问从“为何训练”延伸到“训练什么、如何校准、如何比较、为何保留回退”。记忆和自动研究各讲 2 分钟。

路由必须掌握的直觉：

- 完整候选概率是条件概率连乘，log-prob 相加方便稳定计算；不能只看候选第一个 token。
- 正逆序平均意味着需要两种提示分别计算；“共享一次 prefill”指每种顺序内的候选共享。
- LoRA 更新适配器参数；过程经验通过外部记忆影响输入、不更新模型参数。这是两个独立机制。
- 温度缩放调整分布的尖锐程度，不改变该分布的 top-1 排序，但会影响是否被阈值接受。
- AUTO_RESEARCH 总是完整确认；高置信也可能误解“允许自动做但没有研究主题”。
- 当前默认仍为 LLM；可选级联的效果不能说成已经覆盖真实用户流量。

## 第三天：数字、取舍和模拟问答（6 小时）

1. **1 小时：20、26、27、29、32、60。** 准备 SQLite、任务表、恢复、执行代次、SSE、FastAPI 的选型理由。只需会解释本项目为何这样用，以及规模增长后可能要改什么。
2. **1 小时：49、51、67＋数字备忘。** 为简历五条主线各写一张六行卡：问题、方法、样本/基线、结果、代价、对应材料。
3. **1 小时：52、54、56。** 选一个真实失败：MMR 实现偏差或路由边界误触发。讲清怎么发现、怎么处理、怎样比较及还有什么问题。
4. **3 小时：三轮模拟。** 第一轮 90 秒介绍＋架构；第二轮集中深挖路由或 RAG；第三轮随机混问数字、记忆、恢复和 Auto Research。每轮讲 20–30 分钟，再针对卡点补材料。

至少能区分这些数字：

## 每道题怎样学，才能在面试中说出来

第一遍先理解例子，再将答案压缩成 4–6 个关键词。关掉页面，用自己的话讲 40–60 秒，再追问两层。

推荐回答结构：**遇到的问题 → 实现的机制 → 一个具体例子或结果 → 取舍。** 数字挑一个最贴合问题的；实验细节在被追问时展开，避免开场报完所有历史分数和限制。

拿路由练习：

- 第一层：为什么从纯 LLM 改成级联？
- 第二层：小模型到底如何打分，LoRA 的目标是什么？
- 第三层：置信度怎样使用，为什么 AUTO 一律确认？
- 第四层：160 题怎样划分，与基线怎样比较，98.75% 能说明什么？

能换个问法继续解释，才算掌握这题。若只能重复原句，就回到网页例子，把抽象词换成具体输入与输出。

## 三天结束时的验收

- [ ] 脱稿讲 90 秒项目介绍，围绕用户问题、核心机制和一项结果。
- [ ] 画出架构并讲清一次请求；能区别后台路由、研究执行、页面事件流。
- [ ] 路由和 RAG 各能讲 5 分钟，并接受至少两层追问。
- [ ] 记忆、恢复、自动研究分别能讲清输入、处理、结果和一项限制。
- [ ] 对五条简历主线说清基线、样本和结果，不混淆不同实验。
- [ ] 完整讲出一次真实失败和一个有依据的改进方向。

只学当前投递版本会用到的主线。个人参与经历由自己的实际过程补充；材料里的第一人称示范不需要逐字背诵。源码、历史记录仅在解释卡住时按页面链接查阅，不要求三天内通读。
