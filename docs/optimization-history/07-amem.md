# 07 · A-MEM 真实研究、恢复与独立验证

时间：2026-09-30—10-03。关键提交：`fc467e8`、`8b102ea`、`c84e927`、`62c6f76`、`b95633d`、`abc8a2e`、`4321c5d`、`f43fd1e`、`606a4ec`、`023f537`、`0cd0b67`、`59327cb`。

## 数据与目的

用 A-MEM / LoCoMo 做真实 Auto Research 案例，检查论文/源码阅读、方案形成、Codex 委派、宿主测量和失败反馈。固定 80 个原题、4 段完整对话共 2,080 轮，分 40 开发题与 40 留出题；开发记忆 788 轮，留出记忆 1,292 轮。不是本项目普通记忆检索与 A-MEM 的直接优劣比较。

## 从失败推进到可比较测量

| 阶段 | 发现的问题 | 处理与保留的边界 |
| --- | --- | --- |
| 初始运行与恢复 | 原生权限、认证、服务过载、中断，只有部分记忆或预测 | 保存失败与付费收据；明确恢复同一试验还是新建试验，不把旧部分结果拼成未经说明的完整成功。 |
| 长研究集成 | 原文读不全、引用丢失、反馈过长、冻结输入与输出权限混淆 | 修复连续原文窗口、来源身份、引用定位、失败诊断、条件与用量记录；保留每次中间失败。 |
| r5 方法实现 | 实际完成两版方案、编码和测量，但 MMR 仅用了第一个已选片段相似度 | 开发审计发现错误，应取对全部已选片段相似度的最大值；这是人工介入修正，不宣称 Agent 自主发现。 |
| r6—r7 | 正确 MMR 仍遇执行失败，随后冻结代码恢复测量 | 三组使用同一份完整记忆；r7 为执行/反馈恢复，0 新 Codex，不冒充新方法研发。 |
| 独立留出 | 上游过载导致多次中断 | 显式同轮续接，保留原 20 题预测与原记忆，最终三组各 40 题完成；旧失败不覆盖。 |

## 完整开发比较

40 题有效、39 题证据可评分，三组相同 788 轮记忆，原始预测独立复算一致。

| 指标 | 基线 | 修正后的 MMR | Top10 控制 |
| --- | ---: | ---: | ---: |
| Answer F1 | 45.9624% | 48.1262% | 48.5077% |
| Evidence Recall@5 | 40.8974% | 39.8291% | 34.4872% |
| Evidence Recall@10 | 55.0855% | 58.5043% | 48.6752% |
| Exact match | 2.50% | 0% | 2.50% |

开发结果支持把 MMR 留作 Recall@10 覆盖导向的待验证候选，同时 R5/EM 有退化。Top10 控制 F1 高于候选，远程关键词抽取和回答采样仍有影响。R10 优先级是看过开发结果后的取舍，在独立留出之前才明确预设条件。

## 独立留出终验

2026-10-03 完成，三组各 40 题、同一份 1,292 轮记忆，评分复算一致。

| 指标 | 基线 | MMR 候选 | Top10 控制 |
| --- | ---: | ---: | ---: |
| Answer F1 | 33.68% | 32.54% | 37.10% |
| Evidence Recall@5 | 33.50% | 29.12% | 36.00% |
| Evidence Recall@10 | 42.00% | 41.88% | 42.75% |
| Exact match | 0.00% | 2.50% | 5.00% |

**测量完成，MMR 方法收益未获验证。** 候选未达到预设的“R10 高于基线且 F1 不低于基线”，没有继续调参或换题追分。开发集的 55.09% → 58.50% 仍是历史事实，但不能冒充留出成绩、统计显著性或普遍效果。

最后续接没有新增调研或编码，研究模型接收实际测量并报告未达标；该次 636 个 HTTP 尝试、已报 1,347,433 tokens，1 次未知。整轮留出含过载/中断共 4,343 次尝试、已报 5,162,336 tokens，33 次未知。开发费用另列，未知不按零计。

模型报告曾称本次无错误，独立核查更正为发生 1 次 SSL 请求错误并自动恢复；保留原报告，不修改成无失败版本。完整本地归档含 1,373 个文件，经 ZIP 读回和 SHA 核对，公开仓库仅发布这里的结果摘要与[报告指纹](evidence-index.md)。
