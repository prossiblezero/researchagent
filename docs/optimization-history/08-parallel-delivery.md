## 普通能力与产品交付

在 Auto Research 之外，对普通聊天、LOCAL_QA、头脑风暴做真实验收；修复普通 brainstorm 的页码括号引用问题，并保留首次失败。研究区共享资料、多独立会话和显式分支维持既定模型。

10-03 本地隔离回归记录为 591 项中 584 通过、7 项原生测试按默认配置跳过，离线阶段通过；前端 33/33。数据保全检查保留既有 43 张表记录、配置和木屋界面。这是当时的本地验收，不等于后续 GitHub CI 成绩。

## 有限双路研究 Agent

主控可以调用 `research_parallel`，启动两个各有模型上下文、工具循环、证据和检查点的研究 Agent。使用已有 SQLite 队列完成原子建批、幂等复用、父子取消和固定历史边界，汇总时证据带子任务身份。编码与实验仍使用原有串行执行器；相互依赖的研究保持顺序执行。

真实面板是 4 道公开原文驱动的项目问题，2 组 × 2 次重复 × 串行/并行配置，共 8 个父任务、16 个子研究。两配置使用相同资料、工具和预算；这里测调度方式，不是产品旧版与新版的全量比较。

| 检查 | 结果 |
| --- | --- |
| 子研究交付 | 16/16；4 次双 worker 运行均有实际重叠。 |
| 严格任务转交合同 | 6/8；两次遗漏“不联网”文字。LOCAL_QA/no_web 宿主边界仍有效，没有因此获得联网权限。 |
| 原文与引用复核 | 14 份任务精确匹配答案的 32 项预设事实逐项接受；另 2 份失配答案的 4 项事实单列。 |
| 所有配对交付总时间 | 串行 651.984 秒；并行 706.297 秒，增加 8.33%。 |
| 局部较快案例 | 第二次文档组 132.203 → 98.672 秒，减少 25.36%；首次同组变慢。 |
| 模型用量 | 140 次 HTTP，已报 659,371 tokens，3 次未知。 |

32 项事实来自重复运行，不是 32 道独立问题；两处 ReAct lookup 表述含糊但结合原文接受，审阅保留备注。主控在明确要求并行工具的任务中调用工具，不能由此推断一般自主选工具准确率。

**结论：真实协作完成，总体加速未获证实。** 保留按需并行能力与完整失败，不用最快一次概括整体。完整本地归档有 415 个文件，公开目录提供[结果与来源指纹](evidence-index.md)。功能说明见[并行研究](../parallel-research.md)。
